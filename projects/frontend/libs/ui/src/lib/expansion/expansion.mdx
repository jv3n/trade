# Expansion

Accordion of expansion panels, styled as the lib's cards. `multi` on `<mat-accordion>` lets several
panels stay open at once.

## How to use

<Source
  language="ts"
  code={`import { StbExpansionModule } from '@portfolioai/ui';

@Component({
imports: [StbExpansionModule],
template: \`<mat-accordion multi>…</mat-accordion>\`,
})`}
/>
